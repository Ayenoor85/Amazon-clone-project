# Amazon-clone-project

A front-end clone of the Amazon homepage built using **HTML** and **CSS**.
This project focuses on replicating the layout and design of Amazon with a clean and responsive interface.

---

## 🚀 Features

* ✅ Amazon-like homepage UI
* ✅ Navigation bar with search functionality (UI only)
* ✅ Product sections with images and categories
* ✅ Responsive design (basic)
* ✅ Footer similar to Amazon

---

## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & Layout

---

## 📂 Project Structure

```
amazon-clone/
│── index.html
│── style.css
│── images/
```
